   post-pre-run hook, so the article can reference it.
6. Conclusion: state-actor's generated-state method is the correct way to
   benchmark client worst cases; this incident is the worked example.

     confound, not cause. Summary here; full list remains the appendix.
   - LSM compaction state — compacting between setup and test leaves the
     anomaly standing.
   Rows of the current "refuted" table distribute into these subsections.
5. **The root cause: the pathdb journal** — mechanism with code links
   (journal load/discard, maxDiffLayers = 128, buffer flush condition,
   cap(root, 0)); deploy-window math (DIFF_MAX deployed last, blocks
   24406595-24410441; disk layer at 24406217); probes A/B (0.0 MB cold
   reads with journal; delete it and the accounts cease to exist, head
   rewinds to exactly 24406217); why only these accounts: only state
   written in the final 4248 pre-run blocks lives in journal layers -
   every other class deployed thousands of blocks earlier and was long
   flushed (SAME_MAX straddles the boundary; its benchmark-read salts
   predate it).
6. **The fix, and the proof** — drain + compact recipe; why both legs are
   required (BALANCE/DIFF_MAX/160M: 380 -> 272 with drain alone - the flush
   creates ~103 fresh dense SSTs and LSM recency is physical locality -
   -> 18.5 after compaction in the verdict run (18.3 in the smoke), on
   state-actor's 16.5); the 32-cell three-way verdict table
   rendered from committed data; new figure (per-opcode orig/SA vs
   drained/SA); links to the draft benchmarkoor PR, the drainjournal
   source, and the investigation ledger.
7. **Conclusion — benchmark worst cases on generated state** — replaces
   "Next steps": bulk-generated state (state-actor) has no recency residue
   by construction; snapshot-replay baselines silently inherit pre-run
   recency through the journal and the LSM unless drained + compacted;
   this incident quantifies the failure mode (23x on leaf-reading
   opcodes, 2.8x on code-reading ones).
8. **Appendix** — instrumentation defects collapsible, kept.
